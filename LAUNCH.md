Твоя задача — обеспечить безупречный массовый запуск продукта для пользователей и водителей Томска и поддерживать его стабильность.

> **Как работать.**
> 1. Только минимальные точечные диффы; не переписывай файлы целиком без необходимости. Строгая типизация (без `any`), валидация всех входов через zod, единый конверт ответов API `{success:false,error:{code,message}}`.
> 2. Перед архитектурными развилками (схема БД, новые модули, крупные рефакторинги) — сначала консультация профильного архитектора, потом код.

> 6. Секреты — только в переменных окружения Vercel/GitHub. Никогда не коммить `.env`, ключи и токены.
>
> **Что можно делать автономно:** багфиксы, безопасность, производительность, тесты, инфраструктура, аддитивные миграции, обновление документации.

> **Что нельзя без явного согласования владельца:** удаление пользовательских данных; необратимые деструктивные операции; публикация в каналах от имени проекта; юридические изменения оферты; смена дизайн-токенов бренда.

  - `npm run verify`: 14 тест-сьютов, 95 unit-тестов зелёные (0 ошибок).
  - Сквозной прод-смоук (`scripts/smoke-prod.mjs`): 13/13 шагов пройдено (100%).
  - Комплексный пользовательский E2E (`scripts/e2e-user-journey-test.mjs`): 17/17 сценариев пройдено (100%).
- **Telegram-экосистема (Bot API 8.0 & Mini App):**
  - Поддержка запуска в 1 тап как Telegram Mini App без скачивания приложений из сторов.
  - Бесшовная авторизация по HMAC-SHA256 `initData`.
  - Интерактивные уведомления с inline-кнопками «Принять / Отклонить» для водителей в боте.
  - Кнопка шеринга с генерацией виральных постов для студенческих и районных чатов.
- **Маршрутизация и гео:**
  - 768 остановок Томска с поиском и автоопределением ближайшей точки по GPS.
  - Построение остановок поездки (`routeStops`) и статическая карта Яндекс.Карт.
  - Инверсия спроса: пассажиры оставляют `DemandRequest`, водители берут их в 1 клик.
- **Двустороннее доверие:**
  - Внутренний чат поездки (`TripChat`) для оперативной связи перед посадкой.
  - Взаимные отзывы с раздельными рейтингами водителя и пассажира.
  - 15-минутный льготный период бесплатной отмены (защита от случайных броней).

## 3. Операционный чек-лист массового запуска (Launch Runbook)

### Фаза 1: Финальная проверка инфраструктуры (D−1)
1. **Переменные окружения в Vercel Production:**
   - `DATABASE_URL` (Neon PostgreSQL sslmode=require)
   - `JWT_SECRET` (криптостойкий секрет)
   - `CRON_SECRET` (Bearer-токен для задач обслуживания)
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_BOT_USERNAME`, `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`
   - `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_SUBJECT`
2. **Настройка Webhook Telegram:**
   ```bash
   node --env-file=.env scripts/bot/setup-webhook.mjs
   ```
   Убедиться, что Webhook зарегистрирован с `secret_token`, кнопка меню Mini App установлена, а брендинг и команды загружены.
3. **WAF & Rate Limiting:**
   - В панели Vercel Security включить правило Rate Limit на `/api/auth/*` (30 req/min на IP).

### Фаза 2: Посев первичной ликвидности (D-Day, утро)
1. **Заполнение первых коридоров (Atomic Networks):**
   - Запустить генерацию базовых маршрутов водителей-партнёров:
     ```bash
     node --env-file=.env scripts/seed-first-routes.mjs
     ```
   - Ключевые коридоры утра:
     - *Каштак (Мира / 79 Гв. Дивизии) → Центр / Вузы (ТГУ, ТПУ, СибГМУ)* к 08:00–08:30.
     - *Зелёные Горки (Архитекторов / Энтузиастов) → Пл. Ленина / ТГУ* к 08:15.
     - *Южные Ворота → Пл. Южная / Кирова* к 08:30.
2. **Проверка витрины:**
   - Открыть ленту: карточки утренних поездок отображаются с ценами (80–120 ₽) и доступными местами.

### Фаза 3: Анонс и привлечение (D-Day, день)
1. **Студенческие каналы Томска (Telegram):**
   - Публикация в пабликах студсоветов и общежитий (ТГУ, ТПУ, СибГМУ).
   - Месседж: *«Хватит мерзнуть на остановке: поездки по Томску от 80 ₽ в теплых авто студентов и соседей. Запуск прямо в Telegram Mini App!»*.
2. **Районные чаты (Каштак, Зелёные Горки, Южные Ворота):**
   - Точечные посты от имени реальных водителей со ссылкой на конкретную поездку (`TripShareButton`).
3. **Мониторинг биржи спроса (`DemandRequest`):**
   - Отслеживать заявки пассажиров без машин и оперативно направлять их водителям в чатах.

## 5. План реагирования на инциденты (Кризис-план)

| Ситуация | Решение |
|---|---|
| **Регресс/баг в проде** | Vercel → Deployments → Instant Rollback на предыдущий стабильный релиз. |
| **Дефицит водителей** | Активировать таб «Попутчики ждут машину», направить целевые уведомления водителям по коридорам. |
| **Спам/флуд в чатах поездки** | Срабатывает встроенный спам-фильтр (`spam-filter.ts`); при необходимости — бан аккаунта из `/admin/verifications`. |
| **Ошибка Telegram Webhook** | Перезапустить `scripts/bot/setup-webhook.mjs`, проверить статус через `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`. |
