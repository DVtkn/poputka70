# Оформление Telegram-бота «Попутка70»

Готовый пакет графики и метаданных для автоматического или ручного внедрения в Telegram-бота.

## Файлы в этой папке

- `avatar.png` (`512×512` PNG) — **основная аватарка бота** (вариант 1: фронтальный силуэт двух попутчиков на фоне тёмной тайги).
- `avatar-front.png` (`512×512` PNG) — копия основного варианта для явного выбора.
- `avatar-isometric.png` (`512×512` PNG) — запасной вариант 2 (изометрия 3/4 с дугой маршрута).
- `avatar-cabin.png` (`512×512` PNG) — запасной вариант 3 (крупный план салона для высокой читаемости на 40px).
- `cover.png` (`640×360` PNG) — обложка экрана «Что умеет этот бот?» (`16:9`, точный размер BotFather).
- `branding.json` — структурированный манифест для ИИ-агента: файлы, палитра, тексты, команды и шаги внедрения.

## Быстрое внедрение

1. **Автоматическая часть (через Telegram Bot API):**
   ```bash
   node --env-file=.env scripts/bot/setup-webhook.mjs
   ```
   Скрипт установит Webhook, кнопку Mini App, команды (`/start`, `/search`, `/recent`, `/help`), имя бота (`setMyName`), описание (`setMyDescription`) и краткое био (`setMyShortDescription`).

2. **Загрузка изображений в `@BotFather`:**
   *(Стандартный HTTP Bot API не позволяет устанавливать аватарку и обложку бота программно — это делается через `@BotFather`.)*
   - `/setuserpic` → загрузить `public/bot/avatar.png` (`512×512` PNG)
   - `/setdescriptionpic` → загрузить `public/bot/cover.png` (`640×360` PNG)

Предпросмотр в макете Telegram доступен в приложении по пути `/bot-design`.
